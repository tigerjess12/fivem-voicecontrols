How it works

Hold the key, speak, release to send the command to the FiveM client console. Speech recognition runs offline on your PC. Nothing is recorded to disk unless Debug is ticked.

Commands is a JSON list. Each entry has say (words that trigger it, including likely mis-hearings), send (the console command) and args: callsign (letters then digits), digits, text or none. Letters can be spoken as letters or NATO words, numbers as digits or words. Empty uses the built-in sam and p commands.
