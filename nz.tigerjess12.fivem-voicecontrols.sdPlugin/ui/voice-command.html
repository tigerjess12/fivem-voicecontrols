How it works

Hold the key, speak, release to send the command to the FiveM client console. Speech recognition runs offline on your PC. Nothing is recorded to disk unless Debug is ticked.

Commands is a JSON list. Each entry has say (words that trigger it, including likely mis-hearings), send (the console command) and args: callsign, plate, vehicle (description, "plate", then the registration), digits, text or none. Optional: options, required, minLength, maxLength, cooldown. Letters can be spoken as letters or NATO words, numbers as digits or words, but only for the commands that expect them. Empty uses the built-in commands.
